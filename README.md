# RENAR

**Requirements Engineering and Normative Adaptive Regulation**
Инженерия требований и нормативная адаптивная регуляция

> Самостоятельный нормативный стандарт управления требованиями, спецификациями и
> контрольными примерами в проектах, где реализацию выполняют AI-агенты.

**[renar.tech](https://renar.tech)** · CC BY-SA 4.0

---

## Какую задачу решает

SENAR отвечает на вопрос **«при каких условиях работу можно считать сделанной»**.
RENAR отвечает на предшествующий ему вопрос — **«что именно требовалось сделать»**.

Когда реализацию ведёт агент, второй вопрос перестаёт быть очевидным. Требование,
существующее только в переписке, не переживает смену сессии; спецификация, которую
можно молча переписать под уже написанный код, не является спецификацией.
RENAR задаёт форму, в которой требование фиксируется, изменяется и предъявляется
как основание для приёмки.

Стандарт не зависит от типа хранилища: он одинаково применим к системе контроля
версий и к документо-хранилищу.

## Отношение к SENAR

RENAR и SENAR — **равноправные дополнения** друг друга, примерно как ISO 29148
дополняет ISO/IEC 12207: общий словарь, общие ценности, отдельные документы,
которые хорошо работают вместе.

**Ни один не является частью другого.** RENAR применим без SENAR, SENAR применим
без RENAR, и каждый остаётся осмысленным в одиночку.

## Пять уровней зрелости

| | Уровень | Смысл |
|---|---|---|
| **RENAR-1** | Стихийный | требования существуют, но не зафиксированы как артефакт |
| **RENAR-2** | Зафиксированный | требование неизменяемо после согласования; изменение — отдельный артефакт |
| **RENAR-3** | Учитываемый | требования связаны с работой, которая их реализует |
| **RENAR-4** | Верифицируемый | по каждому требованию есть проверка, дающая вердикт |
| **RENAR-5** | Оптимизирующий | расхождения между требованием и реализацией измеряются и сокращаются |

## Реализации

**[TAUSIK](https://tausik.tech)** — эталонная реализация SENAR, поддерживает
уровни RENAR: `tausik status` печатает текущий уровень, а трассу рассуждения за
ним описывает документация фреймворка.

Стандарт применим и без инструментов — руками, шаблонами и чек-листами.
